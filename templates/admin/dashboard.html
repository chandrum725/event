JSON API

The same actions are available to scripts. Take the CSRF token from GET /api/admin/session and send it in the X-CSRF-Token header.

  • GET /api/media – the public feed: published items only
  • GET /api/admin/media?visibility=all|published|private – every item, private ones included
  • POST /api/admin/media – multipart upload: file, poster, title, category, kind, visibility
  • POST /api/admin/media/<id> – change the title, category or visibility
  • DELETE /api/admin/media/<id> – delete the row and its files
  • GET /api/health – Flask and MySQL status
